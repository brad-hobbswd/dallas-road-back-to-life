# Dallas and the Road Back to Life

A narrative book project following Dallas’s journey through struggle, recovery, and the road toward renewed life. The online edition includes front matter, six chapters, an epilogue, conclusion, and author information.

## Live Website

https://brad-hobbswd.github.io/dallas-road-back-to-life/

## What the Website Includes

- Prologue, foreword, preface, and dedication
- Six chapters
- Epilogue and conclusion
- Author information

## Technology

This is a static website published through GitHub Pages. The repository contains the HTML pages and any supporting styling, scripts, and image assets used by the site.
